# onboarding

Four-slide first-run walkthrough. The gnome (assets/reflect-gnome.png) speaks
in a speech bubble on each slide; brief text covers only the key ideas:
welcome and privacy, I'm in it, Log then Patterns, and the four-tab map.
It is not a feature tour of everything.

Shown once from Today when neither `onboarded` nor `onboarding_seen` is set.
Finish or Skip sets `onboarding_seen` and continues to Setup on a first run.
Replayable any time from Me ("How KnowMe works"); replay returns to the tabs.
No new data is collected and nothing leaves the device.

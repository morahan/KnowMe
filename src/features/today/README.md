# today

Days since last time per habit (big and centered, singular for one day), today's activity in quiet text without outcome labels, and the **I'm in it** button — the only accent-filled thing on the screen. The last-time query still selects stored `used` moments.

Route: `app/(tabs)/index.tsx`. Uses: `db/repos/moments`, `db/repos/habits`, `ui/Stat`, `ui/PrimaryButton`.

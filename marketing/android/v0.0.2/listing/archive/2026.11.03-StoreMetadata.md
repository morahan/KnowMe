## Data safety (paste-ready)
- No data shared with third parties.
- Data collected (optional, user-initiated): app activity (anonymous habit summary) — only when the user taps Reflect; processed ephemerally, not stored.
- All other data stays on-device. Encrypted in transit (HTTPS) for the Reflect call.
- No account creation. Users delete all data by deleting the app (state this in the form notes).

## Declarations
- **Content rating (IARC):** answer honestly; adult habit/substance journaling themes via user-generated content.
- **Health apps declaration:** journaling / self-reflection. No diagnosis, treatment, or medical-device claims.
- **App access:** no login; all features reachable. Reflect needs 2–3 logged moments (or Me → Load demo data).

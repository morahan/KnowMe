## Data safety (saved)
- Collects required data: **Yes**. Shares with third parties: **No**. Encrypted in transit: **Yes**.
- Accounts: the app does not allow account creation; no outside login.
- Deletion: no request flow; data is deleted automatically within 90 days.
- Data types, all sent only when the user taps Reflect, so all **optional**:

| Type | Why | Ephemeral | Purpose |
|---|---|---|---|
| Health and fitness → Health info | habit names, moment counts, times, intensity in the summary | Yes | App functionality |
| App activity → Other user-generated content | reasons, and notes only if switched on | Yes | App functionality |
| Device or other IDs | random per-install ID; proxy keeps it in memory for one hour to rate-limit | No | App functionality, Fraud prevention/security |

The store page shows "No data shared", "Device or other IDs" collected, and "Encrypted in transit".

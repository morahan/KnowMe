## Age rating (set)
Answers: alcohol, tobacco or drug use or references **infrequent/mild** (habit presets name them);
mature or suggestive themes **infrequent/mild** (habits, crisis lines); health or wellness topics **yes**;
everything else none/no (no gambling for money, no simulated gambling, no user-generated content shared
with others, no messaging, no web access, no ads). Override: **18+**, matching the 18+ target audience on
Google Play. Apple's computed rating before the override is 17+.

## App Privacy (nutrition label) — website only, not in the API
**Published 2026-11-07** (matches the Play Data safety answers): data collected **Yes**;
**Identifiers → Device ID** only, used for **App Functionality** only (the install ID the proxy keeps in
memory for an hour to rate-limit Reflect), **not linked** to identity, **not used for tracking**. The product
page shows "Data Not Linked to You: Identifiers". The Reflect summary is used once to write the letter and is
not stored, so under Apple's definition of "collect" it is not declared. No tracking → no ATT prompt required.

## App Review Information
Contact: Michael Morahan, `support@knowmejournal.com`, the owner's phone (set). No sign-in required.

Notes (set):
```
No account or login. All features work offline except Reflect.
To try Reflect: log 2–3 moments (or Me → Load demo data), open Patterns, tap "Reflect on my week".
Reflect writes one letter per day (resets at local midnight). A second tap the same day shows a short "try again tomorrow" note — this is intentional.
Crisis safety: typing a crisis phrase (e.g. "I want to die") in any note field shows a 988/911 support card before anything is saved — this is intentional.
KnowMe is a journaling/reflection tool. It gives no medical advice and makes no treatment claims.
Price: paid app at $7.99. No IAP or subscriptions exist in the binary.
```
